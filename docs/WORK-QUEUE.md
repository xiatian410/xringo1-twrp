本文只记录当前优先级和未完成边界；历史测试流水账不再作为执行队列。目标见 [ADAPTATION-GOALS.md](../ADAPTATION-GOALS.md)，候选与交付见 [simulation-report.md](../simulation-report.md)。

## 执行规则

- 工作范围不限于此前六组，按具体故障与实现决定排序，不因此开始全量重复检查。
- **OS4 震动已修好、用户确认正常，退出例行检查。** 仅新报故障或直接回归证据可重新打开。
- backup-manifest 基线设置正常的用户确认保留，没有新故障不重复诊断。
- 相同源码、输入和范围直接复用结果。必要检查通过就结束本批；不反复增加等价夹具或重编未改镜像。
- 只在离线环境操作普通临时文件；不连接手机或操作物理块设备。
- 每个连贯修改批次完成后同步 GitHub，镜像、原厂 blob、私钥和原始日志不公开。

2. **OTA / A/B 安装链**：0062 / 0064 已修正命令和同步拒绝路径。当前构建 ARM64 COW v3 / LZ4 / 64 KiB 已完成普通文件写入、解析和解压往返，见 [范围](OTA-COW-ROUNDTRIP.md)。实际 ARM64 操作执行器 → 快照 extent → COW 接续已覆盖 REPLACE / BZ / XZ 及部分写入失败，见 [操作接续](OTA-OPERATION-COW.md)。短输入的操作返回可为true但内容不完整；上层最终哈希检查仅做源码复核，下一步需接入 DeltaPerformer / VABC 完成 / 最终哈希生命周期，不重复格式叶函数。当前 archive 不具有旧镜像来源清单的历史绑定。
3. **文档与仓库入口**：已统一 README、目标、构建、状态和使用说明；后续按用途更新，避免把逐轮进度复制到多个入口。

温度避让中央摄像头、扩容尺寸边界与 OTA 同步拒绝已进入 bounded-maintenance 候选，见 [交付记录](BOUNDED-MAINTENANCE.md)。刷入目标与 NV 限制、XRING O1 加载页、OTG 发现等既有修正不重新立项。
