# 公开仓库维护约定

用户于2026-11-12授权使用现有GitHub CLI账户创建公开仓库，并要求以后每次文件修改更新同步GitHub，编译文件不上传。

仓库：`https://github.com/xiatian410/xringo1-twrp`。本地维护工作区为`/root/AAA/xringo1-twrp`，公开Git镜像为`/root/AAA/xringo1-twrp-public`。源码维护仍以工作区及其固定平台补丁为准。

每个连贯修改批次完成验证、维护补丁及文档后执行：

```bash
python3 scripts/sync_github.py --push --message "说明本次具体修改"
```

脚本先按明确目录与文本扩展名导出，核对公开清单、补丁哈希、Python/JSON语法，检查私钥和凭据模式；再提交并推送main，最终读取远端分支确认与本地HEAD一致。无需重新申请发布许可。禁止将同步成功只写在说明里而不执行。推送失败保留本地成果并报告原因，后续恢复同步。

允许公开：维护设备树文本、固定commit补丁、档案/资源摘要、构建/提取/审计脚本、测试源码、说明文档。排除：镜像与编译可执行文件、原厂模块/固件/HAL/TA、原始实机日志、完整OTA、私钥和本地工具/缓存。构建镜像保留在本地`imgs/built/`；不创建二进制Release，不启用后台监视器自动上传未经检查的文件。

`SOURCE-MANIFEST.json`记录每个公开文件的摘要和权限，`PRIVATE-ASSETS.json`仅记录未公开构建资源的摘要。历史文档中的`logs/`和`imgs/`链接可能仅在原维护工作区存在；公开摘要不冒充原始报告。

公开checkout不应反向覆盖完整私有工作区。更新从完整工作区单向导出；源码以外文件的变化不构成上传其内容的授权。
